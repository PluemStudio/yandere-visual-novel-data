# Visual Novel Data 🎮

ชุดข้อมูลบทสนทนาระหว่างตัวละครผู้เล่น (`คุณ`) และ `โคบายาคาวะซัง`

## 📂 โครงสร้างข้อมูล

โปรเจกต์นี้ประกอบด้วยไฟล์หลักดังนี้:

- `src/dialogues-data.json`: ไฟล์ข้อมูลบทสนทนารูปแบบ JSON
- `src/index.ts`: ไฟล์ TypeScript สำหรับจัดการและเรียกใช้งานข้อมูล

> **Note:** ข้อมูลในไฟล์ `.json` และ `.ts` มีเนื้อหาที่สอดคล้องกัน โดยถูกจัดเก็บไว้ในสองรูปแบบเพื่อความยืดหยุ่นในการนำไปใช้งาน

## 🤝 Contribution

เรายินดีต้อนรับและเปิดรับความช่วยเหลือจากทุกคนเสมอ! หากคุณต้องการช่วยขยายเนื้อเรื่อง หรือเพิ่มบทสนทนาใหม่ๆ ให้กับเกม สามารถทำตามขั้นตอนด้านล่างนี้ได้เลยค่ะ:

1. **Fork** โปรเจกต์นี้
2. แก้ไขหรือเพิ่มข้อมูลบทสนทนาลงในไฟล์:
    - `src/dialogues-data.json`
    - `src/index.ts`
3. เปิด **Pull Request (PR)** เพื่อส่งการเปลี่ยนแปลงของคุณเข้ามาได้เลย

ขอบคุณมากๆ นะคะที่มาร่วมเป็นส่วนหนึ่งในการพัฒนาโปรเจกต์นี้ด้วยกัน! ❤️
